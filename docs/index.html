claude-saver

對話太長？一鍵換新對話，重點一起帶過去。

Long conversation? Hand it off to a fresh one in one click.

Claude Code 外掛。對話太長時，你一提新功能就跳出「開新對話」按鈕，按下去就開新對話、附上交接重點、封存目前對話。

A Claude Code plugin. Once a conversation gets long, starting a new task pops up a "New conversation" button that opens a fresh session with a handoff brief and archives the current one.

為什麼要用

Why use it

對話越長，每一輪都要重送整段上下文，越來越耗 token、也越慢。在適當的時候換新對話、只帶重點過去，比較省也比較準。

The longer a conversation, the more context is resent every turn, costing more tokens and time. Switching to a fresh conversation at the right moment, carrying over only the key points, is cheaper and more accurate.

功能

Features

改新功能就跳按鈕上下文超過 150k tokens 後，你提新功能時先跳出「開新對話／在這裡做」按鈕。接續、修正、追問照常做。
一鍵交接按下按鈕，或打「換」「開新」：開新對話（編號自動加 1）、附交接重點、封存目前對話。
接棒對話自動獨立新對話移到最上層，並自動封存前一個對話；子對話先移開，不會被一起封存。
群組維持主次同一個專案的對話放進同一個側邊欄群組，側邊欄不會分裂。
Button on new tasksPast 150k tokens of context, starting a new feature shows a "New conversation / Do it here" button. Follow-ups and fixes carry on as usual.
One-click handoffClick the button or type "new": opens a new conversation (number +1), adds a handoff brief, archives the current one.
Successor stands aloneThe new conversation moves to top level and archives the previous one; child sessions are moved out first so they aren't archived too.
Groups keep orderA project's conversations go into one sidebar group, so the sidebar doesn't split.

安裝

Install

這個外掛不在官方商店，桌面版的「瀏覽外掛」找不到它，請用終端機安裝。在終端機裝好後，桌面版也能用。
This plugin isn't in the official marketplace, so the desktop app's "Browse plugins" won't show it. Install it from a terminal. Once installed there, it works in the desktop app too.
  1. 打開終端機：Windows 按開始鍵搜尋 PowerShell；Mac 打開「終端機」。 Open a terminal: on Windows search for PowerShell in Start; on Mac open Terminal.
  2. 貼上這一行，按 Enter（Claude Code v2.1.292 以上）： Paste this line and press Enter (Claude Code v2.1.292 or later):
    claude plugin install claude-saver --marketplace littlehole2025/claude-saver
    如果出現錯誤，可能是版本比較舊（用 claude --version 看），改成分兩行跑： If it errors, your version may be older (check with claude --version). Run these two instead:
    claude plugin marketplace add littlehole2025/claude-saver
    claude plugin install claude-saver@claude-saver
  3. 回到 Claude，開一個新對話就會生效。 Back in Claude, start a new conversation and it's active.

更新

Update

第三方外掛預設不會自動更新，要更新時跑：

Third-party plugins don't auto-update by default. To update:

claude plugin update claude-saver@claude-saver

需求

Requirements

  • 電腦要裝 Node.js（hook 用 node 執行）。
  • 按鈕、開新對話、封存這些功能，只能在 Claude 桌面版的 Code 分頁用。在終端機 CLI 沒有按鈕，Claude 會改用一句話建議你自己開新對話。
  • Node.js installed (the hooks run with node).
  • The button, opening and archiving conversations work only in the Claude desktop app's Code tab. In the terminal CLI there's no button; Claude suggests in one sentence that you start a new conversation yourself.

設定與隱私

Settings and privacy

可以用環境變數 LONG_CHAT_TOKENS（門檻，預設 150000）、LONG_CHAT_STEP（再提示的間隔，預設 50000）、LONG_CHAT_LANG（zh-TW 或 en）調整，詳見 README。

Tune with the environment variables LONG_CHAT_TOKENS (threshold, default 150000), LONG_CHAT_STEP (notice interval, default 50000) and LONG_CHAT_LANG (zh-TW or en). See the README.

這個外掛不連網路、不傳送任何資料，只在你的電腦上讀對話紀錄檔算 token 用量。

The plugin makes no network requests and sends no data anywhere; it only reads the local transcript file to count tokens.
